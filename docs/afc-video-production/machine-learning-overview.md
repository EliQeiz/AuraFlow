# AFC lesson production brief: Machine Learning From Examples

## Purpose

An original five-minute AFC orientation lesson for complete beginners. It explains machine learning through a small retail forecasting example before introducing data, features, labels, training, testing, learning types, responsible use, and the next lesson.

## Delivery package

The render script creates the following files under `artifacts/afc-machine-learning-overview/`:

- `afc-machine-learning-overview.mp4`: 1080p narrated lesson, approximately five minutes.
- `afc-machine-learning-overview-preview.mp4`: a silent ten-second teaser for AFC cards.
- `afc-machine-learning-overview.vtt`: timed captions.
- `afc-machine-learning-overview-thumbnail.png`: YouTube thumbnail.
- `youtube-upload.md`: title, description, chapters, tags, and accessibility checklist.

## Creative direction

- Original AFC sketchboard style: warm white paper, blue and violet ink, cyan highlights, rounded diagrams, and calm movement.
- No Simplilearn logo, wording, scenes, drawings, or narration is reused.
- Example context: forecasting stock for a neighbourhood shop. The example is illustrative; it does not imply that automated forecasts replace human judgment.
- Narration: clear conversational English, paced for beginner learners. The generated desktop voice is a production draft; replace it with an approved human or licensed neural voice before publishing a public course.

## Lesson sequence

1. What machine learning is and is not.
2. A familiar prediction problem.
3. Historical examples become data.
4. Features and labels.
5. Training as pattern fitting.
6. Testing on unseen examples.
7. Supervised learning.
8. Unsupervised learning.
9. Useful applications.
10. Success measures and human decisions.
11. Bias, privacy, and responsible use.
12. A practical next step.

## AFC release gate

After upload, use an unlisted YouTube video in the course lesson and attach the 10-second teaser as AFC-hosted preview media. Do not claim that YouTube can prove attention. AFC should track player progress and require an in-video checkpoint plus a server-scored quiz before releasing the next lesson.
